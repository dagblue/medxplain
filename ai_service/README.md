# MedXplain AI Service

FastAPI microservice that runs the local HuggingFace models for NER, Assertion, and Summarization.

## Quick Start (3 ways)

### Option 1 — npm script (from medxplain/ folder)
```bash
npm run ai:start
```

### Option 2 — Double-click
Double-click `start.bat` in this folder.

### Option 3 — PowerShell
```powershell
powershell -ExecutionPolicy Bypass -File setup.ps1
```

### Option 4 — Manual
```bash
cd medxplain/ai_service
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

---

## Run Both Servers at Once

From the `medxplain/` folder, open **two terminals**:

**Terminal 1 — AI Service:**
```bash
npm run ai:start
```

**Terminal 2 — Next.js:**
```bash
npm run dev
```

Or on Windows, one command opens both in separate windows:
```bash
npm run dev:all
```

## Endpoints

| Method | Path | Description |
|---|---|---|
| GET | `/health` | Check service + loaded models |
| POST | `/ner` | Extract medical entities |
| POST | `/assertion` | Classify clinical assertion |
| POST | `/summarization` | Generate English summary |
| POST | `/pipeline` | Run all 3 models in sequence |

## Models

| Model | Architecture | Checkpoint |
|---|---|---|
| NER | BertForTokenClassification | `../NER/checkpoint-48561/` |
| Assertion | BertForSequenceClassification | `../ASSERTION/checkpoint-104652/` |
| Summarization | BartForConditionalGeneration | `../SUMMARAZATION/checkpoint-115620/` |

> **Note:** Amharic summarization is not yet enabled. English only.
